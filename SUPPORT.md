# Getting help

| You want to… | Go here |
| --- | --- |
| Ask how something works | [Discussions → Q&A](https://github.com/dexladder/dexladder/discussions/categories/q-a) |
| Report something broken | [Bug report](https://github.com/dexladder/dexladder/issues/new?template=bug_report.yml) |
| Suggest a feature | [Feature request](https://github.com/dexladder/dexladder/issues/new?template=feature_request.yml) |
| Suggest an academy lesson | [Lesson request](https://github.com/dexladder/dexladder/issues/new?template=lesson_request.yml) |
| Report a vulnerability | [SECURITY.md](SECURITY.md) — **not** a public issue |
| Start contributing | [CONTRIBUTING.md](CONTRIBUTING.md) and the [good first issues](https://github.com/dexladder/dexladder/labels/good%20first%20issue) |

There is no support email and no account system, because there are no accounts.
Everything happens in the open on this repository.
