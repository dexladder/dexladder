# Code of Conduct

## The short version

Be decent. Argue with the code, not the person. No harassment, no bigotry, no
spam, no shilling.

## Specific to this project

DexLadder is a **zero-real-money** project. The following are out of bounds in
issues, pull requests and discussions:

- Promoting a token, exchange, signal group, referral link or paid course.
- Asking for, or offering, financial advice or price predictions.
- Requesting features that connect the simulator to real funds.
- Posting wallet addresses or soliciting donations from other users.

## Scope

This applies to the repository, its discussions, and anywhere someone is
representing the project.

## Enforcement

Report a problem by opening a **private security advisory** or emailing the
address in `SECURITY.md`. Maintainers may edit, hide, lock or delete content,
and may block accounts, without further discussion.
